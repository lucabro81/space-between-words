# space-between-worlds

sbw is a framework to build and run MUDs (text worlds) and federations of
worlds. This repo currently holds two blocks:

| Block | Crate | Spec |
|---|---|---|
| 1 — Kernel (Nucleo) | `sbw-kernel` | `docs/specs/spec-01-nucleo.md` |
| 2 — Event log (Registro eventi) | `sbw-eventlog` | `docs/specs/spec-02-registro.md` |

Specs and glossary are in Italian. Code, comments, commit messages, issues and
PRs are in English. See `AGENTS.md` for the development workflow and quality gate.
